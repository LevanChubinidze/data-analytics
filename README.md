# Data Analytics Portfolio

This repository contains my practical work, exercises, and projects completed while studying Data Analytics, SQL, Python, Statistics, and A/B Testing.

The objective is to build a strong foundation in data analysis and demonstrate practical analytical skills through hands-on projects.
